# 🧠 Interview Prep – Fundamentals That Actually Matter

This repository is a **personal interview-preparation notebook**, built in public so others can benefit too.

It contains **small, focused programs** written to deeply understand **core concepts** that are frequently tested in technical interviews—especially for **C++ / systems / core CS roles**.

No frameworks.
No magic.
Just fundamentals.

---

## 🎯 Why this repo exists

* To **revisit basics quickly** before interviews
* To **understand “why”**, not just “what”
* To keep examples **short, readable, and intentional**
* To act as a **living reference**, not a dump of solutions

Each file is written with the mindset:

> *“If I can explain this clearly, I understand it.”*

---

## 🧩 What you’ll find here

* Small standalone programs (usually one concept per file)
* Clear naming and minimal boilerplate
* Topics like:

  * Object lifetime & ownership
  * Copy vs move semantics
  * Pointers, references, and memory
  * STL behavior & pitfalls
  * Basic algorithms & data structures
  * Common interview traps

No hand-wavy code. Everything is deliberate.

---

## 🛠 How to use this repo

* Pick a file
* Read it end-to-end
* Modify it
* Break it
* Fix it
* Explain it out loud

If you can do that, you’re interview-ready for that topic.

---

## 👥 Who this is for

* Engineers preparing for **C++ and CUDA**
* Anyone who wants to **strengthen fundamentals**
* People who prefer **small, sharp examples** over large projects

---

## 📌 Philosophy

> Interviews don’t test libraries.
> They test **clarity of thought**.

This repo is my attempt to sharpen that clarity.
